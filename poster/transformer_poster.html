Attention Is All You Need
Transformer 模型架构详解 —— 自注意力机制与序列建模的革命

Transformer 提出了一种完全基于注意力机制的序列建模架构，彻底摒弃 RNN 与 CNN 结构。该设计消除了循环计算的顺序瓶颈，实现对序列任意位置间依赖的直接建模，极大提升并行计算能力。在 WMT 2014 英德翻译任务中取得 BLEU 28.4 的当时最优成绩，仅用 8 块 P100 GPU 训练 12 小时完成。

01 / BACKGROUND
研究背景与动机

Transformer 提出前，序列建模的主流方法为 RNN 及其变体 LSTM/GRU。这些模型在时间步 t 的输出必须依赖 t-1 步结果，导致无法并行计算，随序列增长训练速度受限明显。

注意力机制虽已被引入（Bahdanau 2014），但仍与 RNN 结合使用。CNN 可并行但感受野有限，远距离依赖需堆叠多层才能覆盖。

顺序瓶颈 长距离依赖 并行化受限
02 / ARCHITECTURE
整体架构设计

Transformer 采用编码器-解码器结构，各由 N=6 层堆叠组成，每层包含两个子层：

多头自注意力（Multi-Head Self-Attention）
前馈网络（Position-wise FFN）
编码器-解码器注意力（Cross-Attention）
残差连接 + 层归一化（Add & Norm）
03 / POSITION
位置编码机制

由于模型无循环结构，对序列位置无感知能力，因此引入位置编码（Positional Encoding），与词嵌入相加送入网络。

原论文采用正弦 / 余弦编码：

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
固定函数 可学习嵌入 RoPE / ALiBi
04 / ATTENTION
缩放点积注意力 与 多头注意力

缩放点积注意力：输入查询矩阵 Q、键矩阵 K、值矩阵 V，先计算点积并除以 √d_k 进行缩放（防止梯度消失），Softmax 后乘以 V 得到加权输出。

Attention(Q, K, V) = softmax( Q · Kᵀ / √d_k ) · V

多头注意力：将 Q、K、V 投影到 h 组不同子空间（d_k = d_model / h），每组独立执行注意力计算后拼接，再经线性变换还原维度。不同头可关注不同的子空间与位置关系，综合多种注意力模式，且总计算量与单头相当（h=8, d_k=64）。

05 / COMPARISON
Transformer vs RNN / LSTM / GRU 对比
特征维度 RNN / LSTM / GRU Transformer
并行计算 ❌ 逐时间步递归，无法并行 ✅ 全序列同时计算，高度并行
长距离依赖 路径长度 = n，需逐步传递，LSTM 门控缓解但未解决 路径长度 = 1，自注意力直连任意两点
计算复杂度 O(n · d²)，需 O(n) 顺序步 O(n² · d)，仅需 O(1) 顺序步（n < d 时更优）
梯度传播 易梯度消失 / 爆炸，门控缓解 残差连接 + LayerNorm，梯度传播稳定
内存开销 O(n)，内存友好 O(n²) 注意力矩阵，超长序列受限
实际性能 适合短序列 / 在线生成，训练较慢 大规模 NLP 任务 SOTA，比等规模 LSTM 快 3–4 倍
06 / IMPACT
主要贡献、局限与长远影响

Transformer 开创了 NLP 的新纪元，"预训练 + 微调"范式的基础：BERT 使用编码器，GPT 系列 使用解码器，大规模语言模型均以此为基。后续 RoPE、ALiBi、稀疏注意力（BigBird、Linformer）、Transformers-XL 等均是对其直接扩展。

主要局限：注意力矩阵随序列长度平方增长（O(n²)），超长文本内存压力大（BERT 常限制 512 token）；全局平均操作可能降低表示分辨率，需多头设计缓解。
